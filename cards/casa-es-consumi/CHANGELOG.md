# Changelog — Casa ES Consumi

## [1.0.0] - 2026-09-13
### Added
- Live total home consumption.
- Seventeen preconfigured appliance power sensors with individual thresholds.
- Automatic sorting from the highest to the lowest active load.
- Responsive OIKOS grid and dynamic blue, amber and red colours.
- Editable entities, labels, thresholds and inactive-device visibility.
