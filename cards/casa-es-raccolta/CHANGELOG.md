# Changelog — Casa ES Raccolta Differenziata

## [1.0.0] - 2026-09-12
### Added
- Reads scheduled collections from `calendar.raccolta_rifiuti`.
- Supports multiple collections on the same day and irregular dates.
- Shows today, tomorrow and the next 3, 7 or 14 days.
- Includes an installable Home Assistant package for the future-events sensor.
- Recognises Sterpaglie, Umido, Carta, Vetro, Indifferenziata and Plastica.
