# Changelog — Casa ES Ventole e Stufetta

## [1.1.0] - 2026-09-13
### Added
- Separate Home Assistant scripts for turning a heater on and off.
- Green heater card while on and red heater card while off.
- Optional live state entity with a persistent last-command fallback.

## [1.0.0] - 2026-09-12
### Added
- Reusable switch card for fans and portable heaters.
- Configurable entity, label and device type.
- Live state, themed active color and Home Assistant more-info shortcut.
